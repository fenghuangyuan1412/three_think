# three_think · 马尼拉

> 1821 年，马尼拉港。西班牙人统治菲律宾已经两百五十年，但港口的权力背后，
> 本地商人早已建立起通往邻近岛屿与亚洲大陆的秘密航线。
> 肉豆蔻、丝绸、玉、人参装满平底船，在夜色里走私进港——
> 而海盗正在暗处等着那些跑不掉的船。

一个用 Three.js 做的 **3D 桌游**，3–5 人，同一台设备上轮流操作。

玩法参考 2005 年的德式桌游 **《马尼拉》(Manila)**（Franz-Benno Delonge 设计）。
本项目是独立实现：规则机制可参考，但**不使用任何原版美术与文案**，
棋盘、船只、棋子全部由代码生成。

## 怎么玩

一局由若干**航程**组成。每段航程是四步：

### ① 竞标港务长

每段航程开场，所有人竞标「港务长办事处」。起拍 1 元，顺时针轮流加价或过牌，
**过牌就不能再加入**。除一人外全部过牌，那人得标、付钱、成为港务长。
出价上限 = 现金 + 未抵押股份 × 12。

### ② 港务长办事

只有港务长能做的事：

- **买 1 张股份**（价格随行就市，最低 5 元）
- **从 4 种货里挑 3 种装船**，剩下一种这一程不发货
- **把 3 艘船放进航道**：各自放在 0–5 之间，**三艘船的起点之和必须正好是 9**

### ③ 派小弟 ⇄ 推船

玩家轮流把自己的小弟派到各处赚钱。可以派去：

| 位置 | 靠什么赚钱 |
| --- | --- |
| **货仓**（船上） | 船平安抵达马尼拉，货仓利润由格位上的小弟均分 |
| **港口 A/B/C** | 有船停在你占的港口空格，拿该格的报酬 |
| **修船场 A/B/C** | 有船进厂停在你的空格，由保险仲介者赔偿你 |
| **海盗船** | 停在第 13 格的船会被劫掠，海盗独吞货物 |
| **领航员岛** | 用影响力把船往前推或往后拉 |
| **保险处** | 先拿 10 元，但之后所有修船赔偿由你掏钱 |

派小弟要付该格的费用；**货仓和海盗船必须从最便宜 / 第一格开始填**。
派完一轮就掷骰推一次船：3 颗骰子对应上了船的 3 种货，**越过第 13 格就进港**，
**正好停在第 13 格**会招来海盗。

### ④ 结算与涨价

分配利润、结清保险理赔，然后**抵达港口的货物涨价**。
**任何一种货物涨到 30 元，游戏结束**——现金 + 股份价值 − 抵押欠款，最高者胜。

## 跑起来

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

其他命令：

```bash
npm test             # 单元测试（规则层）
npm run typecheck    # 类型检查
npm run build        # 生产构建
```

左上角有一个实时读数（帧率 / draw call / 三角形 / 随机种子）。
**随机种子是对局记录的一部分**——同一个种子会复现出完全相同的一局。

### 棋盘数值

港口报酬、修船场赔偿、货仓费用与利润都**已对照官方规则书核实**，与原版一致：

| | 费用 | 报酬 |
| --- | --- | --- |
| 港口 / 修船场 A | 4 | 6 |
| 港口 / 修船场 B | 3 | 8 |
| 港口 / 修船场 C | 2 | 15 |

注意 A/B/C 是**递增的到达门槛**——A 只要有 1 艘船抵达就赔，B 要 2 艘，C 要 3 艘。
所以 C 的费用最低但报酬最高，是个高风险高回报的位置。

货仓：肉豆蔻 3 格（费用 2/3/4，总利润 24）、丝绸 3 格（3/4/5，30）、
人参 3 格（1/2/3，18）、玉 4 格（3/4/5/5，36）。
总利润由站在该货仓格位上的小弟**平分**。

**棋盘上每个位置都直接印着「得多少 / 付多少」**，右侧面板还有一份
「本航程收益一览」每轮更新，会算出你此刻放上去大概能拿多少。

## 技术

Three.js + TypeScript + Vite + Vitest。规则层（`src/core/`）是纯函数、零 three.js 依赖，
因此可以脱离渲染单独测试，也便于日后接联机。

想改代码的话，先读 [`agent.md`](./agent.md)（项目纲领，写给改动者）和
[`git.md`](./git.md)（提交规范）；游戏流程细节在 [`docs/game-flow.md`](./docs/game-flow.md)。
